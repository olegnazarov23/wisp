# wisp logo

| File | For |
|---|---|
| `wisp-logo.svg`, `wisp-logo.png` | light backgrounds |
| `wisp-logo-dark.svg`, `wisp-logo-dark.png` | dark backgrounds |
| `wisp-mark.svg` | the ghost alone, on any background |
| `wisp-icon.svg`, `wisp-icon.png` | the ghost on a dark square: avatars and app icons |
| `social-preview.png` | the repository's preview image when its link is shared, 1280×640 |

The ghost's gradient runs from mint `#5EEAD4` through cyan `#22D3EE` to azure `#3B82F6`; the ink is
`#14121F`, white on dark backgrounds. The name is set in Outfit Bold (SIL Open Font License 1.1) and
converted to outlines, so the SVGs need no font.
